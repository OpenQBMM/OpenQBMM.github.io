Validation

Verification and validation

Verification checks that OpenQBMM solves its equations correctly: the unit tests of its algorithms, the comparisons with analytical and reference numerical solutions, and the baseline each case recorded from its last accepted run. Validation checks that the equations describe the physics, by comparison with experiments and molecular dynamics. Each comparison is held to a tolerance set for it.
